  # 🚀 Simulador de Barra de Progresso em Python

  Este é um projeto simples, mas poderoso, que simula o carregamento de um arquivo ou sistema através de uma barra de
  progresso visual no terminal.

  ## 🛠️ Habilidades Desenvolvidas
  Neste projeto, apliquei conceitos fundamentais de lógica de programação:
  - **Módulos `time` e `sys`**: Controle de tempo e manipulação de saída do sistema.
  - **Estruturas de Repetição (`for` e `range`)**: Criação de ciclos de atualização.
  - **Manipulação de Strings**: Uso de f-strings e concatenação de caracteres especiais (`█` e `░`).
  - **Lógica Matemática**: Cálculo de proporção para preencher a barra visualmente.
  - **Controle de Cursor (`\r`)**: Técnica para atualizar a mesma linha no terminal sem pular linha.

  ## 🚀 Como Executar
  1. Certifique-se de ter o Python instalado.
  2. Clone este repositório:
     ```bash
     git clone https://github.com/dannilooSP/python-progress-bar.git
  3. Execute o arquivo:
  python progresso.py
